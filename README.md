# 🌿 Leaf Scan - Plant Disease Detection App

**Leaf Scan** is a mobile application that detects plant diseases using AI models. It offers offline (on-device) and cloud-based model options for flexible, accurate diagnostics. Built with Flutter and integrated with TensorFlow Lite for edge AI.

## ✨ Features
- **Multi-Model Support**:
  - On-Device: MobileNetV3, EfficientNet-B4
  - Cloud-Based: ResNet-152, ViT-Large (API calls)
- **User Workflow**:
  - Capture or upload leaf images.
  - Select AI model (speed vs. accuracy trade-off).
  - View disease diagnosis and treatment suggestions.
- **Core Functionality**:
  - Notifications for scan history.
  - Save images to device.
  - Profile & settings customization.

## 🛠️ Installation
### Prerequisites
- Flutter 3.0+
- TensorFlow Lite (for on-device models)
- Firebase account (for cloud models)
